# My Clients v1.0.0

First public release of **My Clients** — PHP client management, services catalog, Invoice billing, tax (VAT/MVA/PVM/ПДВ), Stripe & PayPal, PDF, and client cabinet.

## Highlights
- Admin: clients, services (1/3/12 mo pricing), invoices, company details, tax, payments API
- Client cabinet: services, pay invoices online, PDF download
- SEO product landing (UK/RU/EN/NO/SV/PL) + full screenshot gallery
- JSON storage, PHP 8+, no MySQL required
- Multi-language README: EN, UA, RU, NO, LT

## Live demo

- Portal: https://bilohash.com/myclient/cms/portal.php
